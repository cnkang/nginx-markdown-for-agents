# 0.9.4 Compatibility Maintenance Plan

## Release status

v0.9.4 is a release candidate and the project has not published it yet. The
latest public stable release remains v0.9.3. Candidate assets become available
only after publication and maintainer approval of the exact candidate SHA.

## Scope

Prepare matching module packages for nginx.org stable 1.30.7 and mainline
1.31.9 across glibc and musl on amd64 and arm64. Verify Ubuntu 24.04
`1.24.0-2ubuntu7.20` and Ubuntu 26.04 `1.28.3-2ubuntu1.13` on both
architectures. Keep Ubuntu-native packages separate from nginx.org DEB/RPM and
module archive outputs.

The release keeps the 20 active directives and defaults, HTTP representation,
metrics and diagnostics, reason codes, and FFI ABI version 3 unchanged. It
does not claim to fix an NGINX vulnerability and does not promote Homebrew
support.

## Evidence and promotion

The candidate release workflow must record builds, module loads, Markdown
requests, and required package assets for the target rows. Ubuntu records must
also capture the installed source and binary revision, ABI provide, Brotli
dependency, and incompatible-module rejection result.

Keep target rows pending while the workflow produces evidence. Promote only
from those records with `tools/release/matrix/promote_matrix.py`, regenerate
the matrix projections, and dispatch the final workflow on the resulting
candidate SHA with `require_blocking=true`.
