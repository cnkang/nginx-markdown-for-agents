# v1.0.0-rc.1 Readiness

**Verdict: CONDITIONAL GO.**

This branch implements and verifies the compatibility gate and the
prerelease packaging path. Two classes of work remain, and a maintainer owns
both. The release identity has to move to `1.0.0-rc.1` and the release-time
evidence has to run on a frozen candidate. No blocking contract defect appeared
in Week 1.

This document does not announce a release. No tag exists, no GitHub Release
exists, and the work published no package.

## What Supports a GO

| Evidence | Result |
|----------|--------|
| Frozen contract surfaces `v0.9.2` against `v0.9.4` | identical for directives, metrics, reasons, diagnostics, and FFI |
| Candidate against `v0.9.4` | no breaking, review, or unverified finding |
| Coordinated source and inventory edit | blocked by the historical anchor |
| Prerelease ordering in Debian | proved with `dpkg --compare-versions` and a real install sequence |
| Prerelease ordering in RPM | proved with `rpm.vercmp`, and the release-first alternative was measured and rejected |
| Publication dependency graph | unchanged, and the release test suite enforces it |
| Homebrew tap | no longer reacts to a prerelease publication |

## What Blocks the Tag

Each item needs a maintainer action or a follow-up commit. None of them needs a
design change.

| ID | Item | Why it blocks | Owner |
|----|------|---------------|-------|
| B1 | Raise the release identity to `1.0.0-rc.1` in `Cargo.toml`, `charts/nginx-markdown/Chart.yaml`, and the Makefile defaults | The tag guard requires the tag to equal the workflow's declared version, and that version must equal `Cargo.toml` | Maintainer commit |
| B2 | Confirm the release-time validators accept a prerelease identity | Several validators parse a three-component version, and they run only for a frozen candidate | Maintainer and release run |
| B3 | Run the artifact-only rehearsal on the candidate commit | The rehearsal proves the package set without a tag | Maintainer dispatch |
| B4 | Run the protected signing rehearsal | Signing needs the `release-signing` environment with a reviewer present | Maintainer |
| B5 | Freeze the candidate SHA into `RELEASE_APPROVED_CANDIDATE_SHA` | Publication requires the exact approved commit | Maintainer |
| B6 | Confirm the repository's immutable-release setting | A prerelease that uploads assets may need a draft first. This is unverified | Maintainer |
| B7 | Add the compatibility job to the required status checks | The gate only blocks merges once the branch protection names it | Maintainer |

## What Was Not Verified Here

| Item | Reason |
|------|--------|
| nFPM package build | nFPM is not installed in this checkout |
| Signed checksums and packages | Needs the protected environment |
| Exact-SHA release qualification | Needs a frozen candidate and the release workflow |
| Docker, fuzz, and soak qualification | Needs the release workflow runtime |
| Update from `0.9.4` to `1.0.0-rc.1` on a real host | Needs published packages |

The local gates prove the logic. They do not substitute for the release-time
qualification, and this document does not claim otherwise.

## Recommended Sequence

1. Land this branch and let the pull-request CI report on the compatibility
   job.
2. Create the RC candidate commit with the version bump from B1.
3. Run `make release-gates-check-094` and the artifact-only rehearsal on that
   commit.
4. Resolve B2 and B6, then record the outcome in the release checklist.
5. Run the protected signing rehearsal and confirm the signature verifies.
6. Freeze the candidate SHA, approve the environment, then create the tag.
7. Publish, then verify that the release carries the prerelease flag and is not
   marked latest.

## Decision Statement

Week 1 supports a conditional go for `v1.0.0-rc.1`. The compatibility contract
is frozen, comparable, and enforced by a blocking gate. The packaging path
produces correctly ordered Debian and RPM versions for a prerelease. The
remaining work is release choreography that needs maintainer authority, not
further design.

The verdict becomes a full GO once B1 through B7 close and the candidate
carries the rehearsal evidence.
