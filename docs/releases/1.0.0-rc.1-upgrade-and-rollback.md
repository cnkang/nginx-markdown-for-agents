# 1.0.0-rc.1 Upgrade and Rollback

The 1.0.0-rc.1 candidate is not yet published. v0.9.4 remains the latest public
stable release. Use the candidate only after publication or with rehearsal
artifacts.

The candidate does not change configuration directives or defaults. Use the
[upgrade guide](../guides/UPGRADE-TO-1.0.0-rc.1.md) to select an artifact that
matches the NGINX origin, version, architecture, and Ubuntu ABI where
applicable. Keep the previous module package before upgrading.

Use the [rollback guide](../guides/VERSION_ROLLBACK-1.0.0-rc.1.md) to verify
the previous module against the exact NGINX package revision before restoring
it. A matching ABI alone does not prove module loadability.
