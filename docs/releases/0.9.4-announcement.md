# NGINX Markdown for Agents v0.9.4

Version 0.9.4 is a compatibility maintenance release for updated NGINX
packages. It preserves all 20 active directives and their defaults, HTTP
representation, metrics and diagnostics, reason codes, and Rust/C FFI ABI 3.

## NGINX package support

| Distribution | NGINX version or package revision | Architectures |
|---|---|---|
| nginx.org stable | 1.30.7 with glibc or musl | amd64, arm64 |
| nginx.org mainline | 1.31.9 with glibc or musl | amd64, arm64 |
| Ubuntu 24.04 LTS | `1.24.0-2ubuntu7.21` | amd64, arm64 |
| Ubuntu 26.04 LTS | `1.28.3-2ubuntu1.14` | amd64, arm64 |

Ubuntu published the package revisions in
[USN-9182-1](https://ubuntu.com/security/notices/USN-9182-1).

## Verification tooling

The Rust E2E harness covers error handling, configuration merge, large
responses, and streaming failure and cache behavior. The module benchmark
gate evaluates thresholds in Rust. Existing verification commands and the
performance verdict format remain compatible.

## Upgrade and verify

Choose the asset for your NGINX distribution, version, and architecture.
Ubuntu archive installations use the native
`nginx-module-markdown-for-agents-ubuntu` DEB. Check the package against
`SHA256SUMS` and verify its signature with `SHA256SUMS.asc`. After installation,
run `nginx -t` and confirm that an `Accept: text/markdown` request returns
Markdown.
