# 0.9.4 Upgrade and Rollback

Use v0.9.4 assets only after publication and maintainer approval of the exact
candidate SHA. Until then, v0.9.3 remains the latest public stable release.

The v0.9.4 upgrade does not change configuration directives or defaults. Use
the [upgrade guide](../guides/UPGRADE-TO-0.9.4.md) to select an artifact that
matches the NGINX origin, version, architecture, and Ubuntu ABI where
applicable. Keep the previous module package before upgrading.

Use the [rollback guide](../guides/VERSION_ROLLBACK-0.9.4.md) to verify the
previous module against the exact NGINX package revision before restoring it.
A matching ABI alone does not prove module loadability.
