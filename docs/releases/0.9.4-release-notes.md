# Release Notes: 0.9.4

**Date**: 2026-11-22

**Status**: Stable release

The latest public stable release is v0.9.4. Download its assets and checksums
from the [GitHub release](https://github.com/cnkang/nginx-markdown-for-agents/releases/tag/v0.9.4).

**Compatibility target**: Non-breaking. The 20 active directives and their
defaults, HTTP representation, metrics and diagnostics, reason codes, and the
Rust/C FFI ABI version 3 remain unchanged.

---

## Summary

The 0.9.4 release prepares module artifacts for current NGINX builds and
Ubuntu's patched NGINX package revisions. NGINX owns its upstream security
fixes. This module release does not claim to fix an NGINX vulnerability. It
lets users install a module built for the NGINX revision they run after
upgrading NGINX.

## Verification tooling

- The Rust E2E harness runs the eight error-handling cases through the
  existing test commands. See [End-to-End Tests](../testing/E2E_TESTS.md).
- The Rust E2E suite checks configuration merge, large responses, and
  streaming failure and cache behavior.
- The Python evidence gate calls a Rust evaluator for module benchmark
  thresholds and keeps the existing verdict report. See
  [Performance Gate](../testing/PERFORMANCE_GATE.md).

## Compatibility targets

| Channel | Target | Architectures and libc | Release verification |
|---|---|---|---|
| nginx.org stable | 1.30.7 | amd64 and arm64, glibc and musl | Build, load, request, and package checks in the release workflow |
| nginx.org mainline | 1.31.9 | amd64 and arm64, glibc and musl | Build, load, request, and package checks in the release workflow |
| Ubuntu 24.04 LTS native | `1.24.0-2ubuntu7.21` | amd64 and arm64 | Exact-revision build, ABI, install, load, and request checks in the release workflow |
| Ubuntu 26.04 LTS native | `1.28.3-2ubuntu1.14` | amd64 and arm64 | Exact-revision build, ABI, install, load, and request checks in the release workflow |

The protected release workflow requires passing evidence for all 12 blocking
targets from the exact tagged commit and workflow run before it publishes
assets. Ubuntu-native checks use the exact package revisions and verify the
distribution ABI and Brotli dependencies.

NGINX published the 1.30.7 stable and 1.31.9 mainline releases on 2026-11-18
([official release announcement](https://nginx.org/index.html)). Ubuntu
published the package revisions above in [USN-9182-1](https://ubuntu.com/security/notices/USN-9182-1).
These upstream changes are not vulnerabilities in this module.

## Packages and compatibility contracts

nginx.org builds and Ubuntu-native builds are separate products. The former
targets the matching nginx.org binary and produces the module archive and
DEB/RPM package families required by the release contract. The latter builds
against Canonical's source package and binary, records the Ubuntu ABI provide,
and produces `nginx-module-markdown-for-agents-ubuntu` DEBs. Do not substitute
one package family for the other.

The release preserves all v0.9.3 tags, assets, and evidence. It also keeps
Homebrew support experimental.
