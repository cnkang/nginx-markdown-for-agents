# 1.0.0-rc.1 Deployment Recommendation

Do not deploy the 1.0.0-rc.1 candidate to production. The candidate is not yet
published, and v0.9.4 remains the latest public stable release.

Use the candidate for release qualification and staging only.

Deploy only the artifact family that matches the NGINX origin and exact
supported version. For Ubuntu, check the package revision and ABI in the
release matrix. For unsigned rehearsal packages, verify the SHA-256 checksum.
For published artifacts, verify the signature and checksum. Test `nginx -t`,
send a Markdown request, and keep the previous module package for rollback.

Wait for the final 1.0.0 release for production deployments.
