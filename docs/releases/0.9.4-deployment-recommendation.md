# 0.9.4 Deployment Recommendation

Do not deploy the v0.9.4 release candidate to production. The project has not
published it yet. The latest public stable release remains v0.9.3. Candidate
assets become available only after publication and maintainer approval of the
exact candidate SHA.

After publication, deploy only the artifact family that matches the NGINX
origin and exact supported version. For Ubuntu, check the package revision and
ABI in the published compatibility matrix. Verify signed checksums, test
`nginx -t`, send a Markdown request, and keep the previous module package for
rollback.
