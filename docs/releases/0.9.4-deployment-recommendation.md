# 0.9.4 Deployment Recommendation

v0.9.4 is the published compatibility maintenance release. Deploy it through
your normal staged rollout and operational approval process.

Deploy only the artifact family that matches the NGINX origin and exact
supported version. For Ubuntu, check the package revision and ABI in the
published compatibility matrix. Verify signed checksums, test
`nginx -t`, send a Markdown request, and keep the previous module package for
rollback.
