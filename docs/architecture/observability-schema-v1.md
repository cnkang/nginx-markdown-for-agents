# Historical Observability Schema v1 path

The 0.9.0 compatibility documentation used this filename for the historical
Schema v1 contract. The current 0.9.2 diagnostics contract is Schema v2 and
lives at [observability-schema-v2.md](observability-schema-v2.md).

This compatibility page remains so historical 0.9.0 release notes and
migration links do not silently resolve to the v2 wire contract.
