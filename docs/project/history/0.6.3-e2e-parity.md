# Rust E2E Scenario Parity

This register maps compatibility shell entrypoints to their canonical Rust
scenario implementation. A migrated wrapper contains no product assertions.
All HTTP fixtures, requests, and assertions live in `tools/e2e-harness/`.
`tools/e2e/` remains the canonical entrypoint for shell scenarios that remain
unmigrated. Migrated wrappers may retain their compatibility name, but
they delegate fixtures, requests, and assertions to `tools/e2e-harness/`.

| Compatibility entrypoint | Rust scenario | Covered behavior | Known gaps |
|---|---|---|---|
| `tools/e2e/verify_brotli_streaming_e2e.sh` | `tools/e2e-harness/src/scenarios/brotli_streaming.rs` (`brotli-streaming`) | Real module conversion for small and large Brotli responses; single-byte upstream chunks; streaming and full-buffer routing; automatic decompression disabled; budget fail-open; malformed, truncated, and trailing input safety; slow-reader backpressure and metrics | Build-disabled linkage is verified by the Ubuntu 22.04 CI build matrix because a running binary cannot toggle compile-time support |
| `tools/e2e/verify_accept_negotiation_e2e.sh` | `accept-negotiation` | Strict, wildcard, force, and explicit-reject Accept behavior | Requires a module-enabled NGINX runtime |
| `tools/e2e/verify_metrics_endpoint_e2e.sh` | `metrics-endpoint` | Loopback metrics endpoint and bounded Prometheus output | Requires a module-enabled NGINX runtime |
| `tools/e2e/verify_conditional_requests_e2e.sh` | `conditional-requests` | ETag, If-None-Match, If-Modified-Since, 304, and HEAD behavior | Requires a module-enabled NGINX runtime |
| `tools/e2e/verify_auth_cache_e2e.sh` | `auth-cache` | Authenticated conversion policy and cache-control rewriting | Requires a module-enabled NGINX runtime |
| `tools/e2e/verify_status_codes_e2e.sh` | `status-codes` | Configured reject statuses and response headers | Requires a module-enabled NGINX runtime |
| `tools/e2e/verify_encoding_chain_e2e.sh` | `encoding-chain` | Content-Encoding chain parsing and decompression routing | Requires a module-enabled NGINX runtime |
| `e2e-harness scenario smoke` | `smoke` | Runtime/bootstrap prerequisite and binary resolution checks | No former shell scenario wrapper; this is a harness-only prerequisite |
