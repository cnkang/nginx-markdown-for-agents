# 0.7.0 Validation Matrix

This matrix documents the validation checks that constitute the 0.7.0
release gate. Each row maps a gate area to the verification commands and
artifacts that the gate validator checks for.

## Gate 1: Build and Header Integrity

| Check | Command | Notes |
|-------|---------|-------|
| FFI ABI drift check | `make build && make check-headers` | C/Rust header sync |

## Gate 2: FFI Boundary Tests

| Check | Command | Notes |
|-------|---------|-------|
| C unit tests | `make test-nginx-unit` | State machine + config parsing |
| Rust unit tests | `make test-rust` | Converter + FFI boundary |
| Layout tests | `make check-headers` | Struct layout and generated-header assertions |

## Gate 4: K8s Release Matrix

> Prior Gate 3 (streaming runtime validation) was intentionally retired for
> the 0.7.0 line. Its coverage moved into the E2E and release gates of the
> current release line, so the historical numbering jumps from Gate 2 to
> Gate 4.

| Check | Command | Notes |
|-------|---------|-------|
| Chart lint/render | `helm lint charts/nginx-markdown` | K8s chart lint is a 0.7.0 gate |
| Chart template render | `helm template test-release charts/nginx-markdown` | Renders all templates with default values |
| Final scope | Chart lint/render validation passes for 0.7.0 GA | Release matrix coverage |

## Gate 5: Release Gate Consistency

| Check | Command | Notes |
|-------|---------|-------|
| Harness check | `make harness-check-full` | Full harness sync |
| Docs check | `make docs-check` | Documentation consistency |
| Release gates strict | `make release-gates-check-070` | Gate validator mode (exit 0 = all gates pass) |
| Rust toolchain pinned | `cargo --version` matches components/rust-converter/rust-toolchain.toml | Release build reproducibility |
