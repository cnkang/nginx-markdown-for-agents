# 0.9.3 Breaking Changes

0.9.3 has no intentional breaking change.

The release keeps the 20 active NGINX directives, their syntax, and their
default values. It keeps the HTTP representation, the metrics and diagnostics
documents, the reason-code registry, and the FFI ABI version 3.

## What can still fail after the upgrade

| Condition | Result | Action |
|---|---|---|
| The module does not match the installed NGINX build | `nginx -t` reports `module is not binary compatible` | Install the artifact for your exact NGINX version |
| An Ubuntu security update changes the NGINX ABI | Apt removes the module package | Install a module built for the new revision |
| A configuration uses a directive that 0.9.2 removed | `nginx -t` reports `unknown directive` | Follow [MIGRATION-0.9.2.md](MIGRATION-0.9.2.md) |

None of these conditions comes from a change in 0.9.3. They come from the
artifact choice or from an older configuration.
