# Migration to 0.9.4

Once the project publishes v0.9.4, operators will not need a configuration
migration. The release keeps all 20 active directives and their
defaults, HTTP representation, metrics and diagnostics, reason codes, and FFI
ABI version 3 unchanged.

The v0.9.4 release candidate is not yet published. Use v0.9.3 release assets
until a maintainer approves the exact candidate SHA and publishes the release.
For the package selection and post-install checks, follow
[Upgrade to 0.9.4](UPGRADE-TO-0.9.4.md).
