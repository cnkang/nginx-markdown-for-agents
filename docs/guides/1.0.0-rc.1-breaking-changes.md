# 1.0.0-rc.1 Breaking Changes

The 1.0.0-rc.1 candidate introduces no breaking changes against v0.9.4.

The 20 active directives and their defaults, the HTTP representation, the
metrics and diagnostics contracts, the reason codes, and FFI ABI version 3 stay
unchanged. The candidate adds release tooling and a prerelease package
identity.

The candidate is not yet published. v0.9.4 remains the latest public stable
release.
