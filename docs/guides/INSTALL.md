# Installation Guide Index

> **Deprecated navigation path.** This file stays as a stable
> navigation entry point for older links and as the package documentation
> layout contract (`/usr/share/doc/nginx-markdown-for-agents/INSTALL.md`).
> It is NOT an installation guide. Do not extend it with install content.
> The canonical installation documentation is
> [INSTALLATION.md](INSTALLATION.md).

The installation instructions now have one canonical document per audience:

- [Installation Guide](INSTALLATION.md) — all supported installation methods,
  including the install script, Homebrew, Docker, and source builds.
- [Package Installation Guide](PACKAGE_INSTALLATION.md) — operator steps for
  downloading, verifying, installing, upgrading, and rolling back DEB/RPM
  artifacts.
- [Package Distribution Strategy](PACKAGE_DISTRIBUTION.md) — release and
  packaging-maintainer contracts, artifact naming, manifests, and signing.
- [Package Compatibility Guide](PACKAGE_COMPATIBILITY.md) — NGINX dynamic
  module compatibility, supported versions, and troubleshooting.

Start with [INSTALLATION.md](INSTALLATION.md) unless you already have a
published package selected for the exact NGINX version and architecture.
