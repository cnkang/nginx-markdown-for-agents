# 0.9.4 Breaking Changes

v0.9.4 is a compatibility release candidate and the project has not published
it yet. The latest public stable release remains v0.9.3. The v0.9.4 assets
become available only after publication and maintainer approval of the exact
candidate SHA.

The release introduces no breaking changes. It keeps the 20 active directives
and their defaults, HTTP representation, metrics and diagnostics, reason
codes, and FFI ABI version 3 unchanged. It does not require a configuration
migration.
